# Leonxlnx/taste-skill — deep-read notes
- Verified: 120,822★, license MIT, last push 2026-11-24, branch main (source: GitHub API search 2026-11-24)
- What it is: A single large agent skill (`design-taste-frontend`, self-versioned "tasteskill 2.5.1") that makes coding agents build marketing/company websites at a claimed "figma.com and x.ai" bar. It bundles a full asset kit (starter HTML, design system CSS, hero layouts, WebGL effects, procedural 3D product renders, a licensed photo library) plus Node scripts that check the finished page in headless Chrome and a "finish gate" Stop hook that blocks the agent from ending the session with fixable FAILs. 1,663 files in the tarball.
- Scope: both (UI design system + copy voice/anti-slop copy linter), narrowly targeted at company websites
- Key files read: README.md, CHANGELOG.md, skills/taste-skill/SKILL.md, skills/taste-skill/references/copy-tells.md (partial), references/gate.md (partial), skills/taste-skill/assets/effects/index.json, assets/effects/halftone-screen/meta.json, examples/v2/CREDITS.md, .claude-plugin/marketplace.json, install.sh (partial), scripts/ dir listing, wc of consistency.mjs (11,485 lines) and copy-lint.mjs (463 lines)
- Mechanics:
  - Business-kind routing first: every page is classified software / gaming / tech / product / service / place; shader effects, scroll scenes and WebGL objects are allowed ONLY on tech kinds (cap of 4 live WebGL contexts), while places/shops/services get photographs + typography + flat colour. Page type is declared in `<html data-type>` and metas that the checker reads.
  - "Deal, never choose by taste": `start.mjs deal --page <kind> --trade <trade>` deals a trade-matched palette + Google Fonts pairing from `library/palettes.json`/`library/type.json`; `assets/layout/deal.mjs` deals 1 of 11 hero layouts; `moments.mjs pick` deals 1-2 "moments". Each command keeps a history JSON so consecutive builds differ (anti-template-look mechanism).
  - Effects = 25 self-contained WebGL/JS visual effects (each `effect.js` + `meta.json` with look/family/motion/cost/palettes; families dither/mesh/light/pattern/photo/grain/material, e.g. halftone-screen, bayer-dither, god-rays, gradient-mesh). Objects = procedural product renders (product-render with build.js + JSON specs of parts). Scenes = 17 scroll-driven scene modules (scene.css/scene.js/demo.html/meta.json).
  - Browser verification: `consistency.mjs` (11.5k lines, 100+ checks) renders the page in headless Chrome served over 127.0.0.1 HTTP (never file://) at 1440/1024/820/768/390, catching empty visuals, broken shaders (GLSL reserved-word lint + forced shader failure), contrast, misaligned columns, section-height drift, placeholder text, invented street numbers, 320px overflow, tap targets. Plus `check.mjs` layout stress tests, `perf.mjs`, `shoot.mjs` screenshots.
  - Finish gate: `gate.mjs --start ...` arms a build (`.taste-skill/build.json` marker); runs checker + copy-lint, emits one terminal line `GATE: PASS/FAIL/OPEN/SETUP/ERROR/OFF`, max 3 fix rounds, never traps the agent (crash or shell blocks once then allows). Waivers go in `.taste-skill/waivers.json` (max 5) with reasons — designed against gaming the checker.
  - Copy layer: `copy-lint.mjs` (~30 ms/page, no browser) counts model-copy "tells" with severities ban/cap/context across two generations (old slop words like "seamless/delve"; second-gen tells like the uniform "house voice", invented specifics, stat strips, two-fragment headings "X. Y."). `copy-tells.md` is explicitly dated November 2026 and warns tells drift per model generation.
  - Photo licensing: `photos.mjs` deals a vetted library (bundled Wikimedia Commons WebP + Unsplash-via-Picsum; later ingests human-reviewed "two reviewers each"), live Commons search accepts only CC0/CC BY/CC BY-SA/PD (no NC/ND), writes one expandable footer credit line. House rule: no captions under any image.
  - House rules (9), including the anti-slop classics: no captions, every visual renders at 4 widths, one section per screen, equal left/right edges, real icons never drawn look-alikes, no violet/lavender anywhere in page design, addresses must not contain house numbers/phones (`.example` contacts).
- 3 non-obvious ideas worth adopting:
  1. The finish gate as a Stop hook with round counting and anti-trap/anti-gaming design: blocks the agent from finishing while fixable FAILs remain, caps at 3 rounds, treats a crash as "block once then allow", records every hook call in `gate.json` history, and uses a waivers file with reasons instead of letting the agent edit the kit to pass checks (it even detects edits to the kit's own files and page code hunting for headless browsers).
  2. "Deal, never choose by taste" — randomised-but-curated dealing of palettes/heroes/moments with per-folder history files so two consecutive builds of the same brief don't look like the same template; this attacks the root cause of AI-slop (every output converging to one look) rather than its symptoms.
  3. Two-generation copy-tell taxonomy with severities (ban/cap/context) and the meta-insight that the strongest current tell is the model's uniform "house voice" and decorative invented specifics — plus literal-trade exceptions ("a climbing harness, bespoke tailoring") and client-name exceptions so the linter doesn't false-positive real copy.
- Flaws / weaknesses:
  - Enormous complexity: 381-line SKILL.md with dense rule prose ("House rules" + 6 sections + checklists) is at the edge of what an agent can reliably follow; much of the burden is pushed onto scripts, but the run procedure (steps 0-7, deals, plans, waivers) is intricate.
  - Heavy lock-in to its own kit: rules like "never edit the kit's files", "build exactly the dealt plan" and starter.html/system.css mean the skill mostly stamps out pages from its own component system; claims of "figma.com and x.ai level" are marketing, unverifiable from the repo.
  - Chrome+Node 22+ runtime dependency and a Stop hook that executes a 891-line script on every session end — a significant trust surface; the README's claim "It installs nothing" is true but it does launch browsers, run local HTTP servers and write `.taste-skill/` state.
  - Vendored photo library (1,663 files incl. bundled WebP photos) bloats install; license hygiene depends on `photos.json` metadata staying correct.
  - Star count (120k) and sponsor-heavy README suggest hype-cycle attention; the repo itself even carries a disclaimer that any crypto token using the name is unaffiliated — a sign of the attention level, not quality.
