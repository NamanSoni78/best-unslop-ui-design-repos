# MrSpideyNihal/FixMySlop — deep-read notes
- Verified: 55★, license MIT, last push 2026-10-28, branch main (source: GitHub API search 2026-11-24)
- What it is: A real, shippable Python CLI linter (pip/npm `fixmyslop`) for AI-agent slop across 5 rule families — ui/ (AI gradients, glows), slop/ (elided code `// ... existing code ...`, narrating comments, stub functions, ts-any), deps/ (phantom/undeclared imports, hallucinated packages), docs/ (hype copy, chatbot residue, dead links, placeholders), sec/ (leaked keys, NEXT_PUBLIC_ secrets, eval, SQLi) — with stable rule IDs, SARIF, GitHub Action, MCP server, Claude PostToolUse hook, baseline mode, safe auto-fixes, and a benchmark with published precision. Not vaporware.
- Scope: both (UI slop + code slop + prose-in-docs; it's an agent-output linter, not a design teacher)
- Key files read: README.md (head 90 + integration greps), fixmyslop/core/slop/ layout, rules_ui.py (head), action.yml, npm/bin/fixmyslop.js, benchmarks/BENCHMARK.md, fixmyslop/utils/update_check.py, test_bait.py, main.py
- Mechanics:
  - Rules engine (fixmyslop/core/slop/: engine.py, rule.py, rules_ui/code/deps/docs/security.py, theme.py, fixers.py, sarif.py, baseline.py): decorator-registered rules with why+fix text per finding; theme-aware — `_theme_vars(ctx)` resolves the project's CSS variables so `colors_in()` can judge gradients in any syntax (Tailwind stops, hex, oklch) against the project's own theme, not blind hexes.
  - CLI loop for agents: `scan -f prompt` emits a full fix brief (issues, exact fixes, the project's design tokens) → agent fixes → re-scan proves it; `--fail-on medium` for CI; `baseline` accepts existing issues and reports only new ones; `fix --safe-only` does behavior-preserving auto-fixes.
  - Integrations: `fixmyslop init --all` writes config + agent rules + skill + MCP server (check_slop, fix_safe, explain_rule, slop_guide) + Claude PostToolUse hook (only the lines Claude just wrote are reported) + CI + pre-commit; GitHub Action (action.yml) with SARIF upload to code scanning; `npx fixmyslop` is a thin launcher that runs the SAME npm-version Python via local install/uvx/pipx (version probe, refuses version drift with an upgrade hint).
  - Benchmark (benchmarks/): 13 pinned public repos — 9 AI-built (Lovable-searched) vs 4 hand-built controls (shadcn/taxonomy, vercel/commerce…) — deterministic rules only (`--no-static`); precision 95% from 80 randomly-drawn findings (seed 2026), all verdicts in labels.json; the 4 false positives are named (pulsing live dot, event-delegation dropdown, two overlay cases — overlay ones fixed + regression tests added); separation table shows AI vs human score grades.
  - Update check: PyPI metadata once/day, 1.5s timeout, silent offline, skipped in CI, `FIXMYSLOP_NO_UPDATE_CHECK` opt-out, never installs.
- 3 non-obvious ideas worth adopting:
  1. Benchmark with a labeled random sample and named false positives that became rules fixes + regression tests ("click-outside modal backdrops... each became a fix plus a regression test") — the precision methodology (seed, sample size, all verdicts committed) is what linters should ship.
  2. Theme-aware color rules: resolving the project's own CSS variables before judging gradients eliminates the classic false positive of flagging a brand-legal color.
  3. The PostToolUse hook scoping trick: report only the lines the agent just wrote, so the signal isn't buried under pre-existing debt (paired with baseline mode for the repo at large).
- Flaws / weaknesses:
  - Small stars (55★) and one author; the AI-vs-human separation benchmark is a proxy: "AI-built" labels come from GitHub search for Lovable projects, and hand-built controls are shadcn/vercel templates — selection bias is possible (though pinned and reproducible).
  - npm path requires Python 3.10+ + uv/pipx on the machine — the "no install step" npx claim is conditional.
  - UI rules are a subset of the whole (the bulk of rules are code-slop/security); as a *design taste* artifact it is narrower than everything else in this batch — it catches tells, it doesn't teach composition.
  - The hosted site (fix-my-slop.vercel.app) downloads public repos to scan — fine, but the README badge mechanism nudges public exposure of repo grades.
