- Mechanics (real linter, not prompt text):
  - The "72-rule UI design linter" is genuine code: `src/analyzer/design-craft.ts` (647 lines) defines DESIGN_CRAFT_RULES as 72 rules — SLOP-COLOR (12), SLOP-TYPE (10), SLOP-LAYOUT (10), SLOP-SURFACE (8), SLOP-COPY (12), SLOP-UX (12), SLOP-TOKEN (8) — each with title + recommendation; `slop-detector.ts` (1,121 lines) implements regex-based detection with exact file:line:column offsets (line-mapping class), e.g. `bg-clip-text`+`text-transparent` → SLOP-COLOR-010, `text-black bg-white` polarity → SLOP-COLOR-003, ≥4 distinct accent hues → SLOP-COLOR-011; `wcag.ts` (204 lines) does real WCAG 2.1 contrast math (relative luminance, AA/AAA thresholds) plus "APCA-inspired" checks. AI_COPY_CLICHES is a compiled list of 100+ cliché phrases with replacements.
  - The 44 scripts question: there are 11 TypeScript sources + 12 compiled dist JS files + 1 build script — no 44-script pile; the repo's heft is in src/analyzer + src/extractor (872 lines) + src/sync (rule-writer 508, token-exporter 375, transformation-rules) + src/mcp/server.ts (434) + bin/unslop.ts (410). All read-only analysis except `init` (writes agent config files) and refactor-plan (writes reports).
  - 7-pillar scorecard → Design Craft Score (mean of capped pillar scores); `--fail-under 95` gate for CI; refactor-plan emits before→after translation table (e.g. `from-purple-500 via-pink-500 to-indigo-500` → `bg-[var(--surface-1)]`, `p-[13px]` → `p-[var(--spacing-12)]`, `transition-all` → `transition-colors motion-reduce:transition-none`) + P0/P1/P2 steps.
  - 10 archetypes are JSON presets with full token contracts (semantic colors, light/dark companions, fluid type, spacing, radii, shadows, motion, "ten archetype-specific design laws"); extract-dna.ts fetches URLs (http/https only, explicit byte/request/stylesheet budgets, custom user-agent) or reads local CSS and infers a token preset.
  - `init` writes per-agent integration files for 8+ agents (Claude/OpenCode/Codex/Cursor/Windsurf/Copilot/Cline/Zed), merge-safe and byte-for-byte idempotent; MCP server is JSON-RPC 2.0 stdio with 4 tools (unslop_audit, unslop_extract_dna, unslop_apply_preset, unslop_refactor_plan).
  - SKILL.md is a 5-step "Principal UI/UX Design Engineer protocol": diagnose (audit) → one aesthetic direction (archetype or DNA; "do not mix archetypes") → structural before surface → polish → verify to 95-100 (A+) with "never suppress a rule to improve the score" and "never claim visual excellence from static analysis alone".
  - CI: npm ci + build + "Verify committed distribution is current" (git diff --exit-code on dist/) + typecheck + tests on Node 20/22; 7 test files incl. v1/v2/integrations/readme-demo tests.
- 3 non-obvious ideas worth adopting:
  1. The committed-dist CI check (`git diff --exit-code -- dist/`) — guarantees the shipped compiled artifact matches the source, a trust measure for an npm-distributed binary.
  2. Refactor plans as literal before→after translation tables with exact source-location steps (P0/P1/P2) rather than prose advice — the audit output is directly executable by an agent.
  3. Design-DNA extraction with explicit budgets and visible warnings ("warnings remain visible rather than silently inventing missing tokens") — honest handling of imperfect reference extraction.
