- What it is: A single SwiftUI-native visual-design skill: "Type one line in your agent. Get back a SwiftUI interface that doesn't look AI-generated" (README.md:18). It packages a design-direction workflow, an anti-slop rule set, a brand-asset protocol, token recipes and a scored review rubric, all Apple-platform-specific (Xcode 16+, iOS 18+/macOS 15+). Marketing claim: shippable interface in 3–30 minutes.
- Scope: UI (SwiftUI only).
- Key files read: README.md (127 lines, full); SKILL.md (270 lines, full); references/anti-ai-slop.md (first 60 lines of 268); file/line inventory of references/ (5 files, 1229 lines) and templates/brand-spec.md (77 lines).
- Mechanics:
  - "Six Ironclad Rules Against AI Sloppiness" (README.md:46-59, detailed in SKILL.md and references/anti-ai-slop.md): (1) Start from context — ask for design system/UI kit/Figma/brand before designing, never blank-canvas invent; (2) "Junior Designer Mode" — hypothesize early, iterate fast, gray placeholders over polished-but-generic; (3) Give 2–3 differentiated variants, not one final; (4) Placeholder > bad implementation — gray placeholder + label, "Never use AI-generated SVG clipart", no emoji-as-icons, prefer SF Symbols; (5) System-first, don't fill — every element must justify existence, "Whitespace is a feature, not emptiness"; (6) Ban AI-slop patterns — purple-blue gradients, emoji icons, rounded cards + left-border accent, generic centered hero over gradient, Inter/Roboto as display fonts on Apple, neon-on-dark #0D1117 cyber, symmetric 3-column grids, AI-drawn SVG illustrations; replacements: single warm accent on neutral, SF Symbols, serif display (New York/Georgia), one signature detail at "120% effort" per screen.
  - Brand Asset Protocol: mandatory 5 steps (Ask → Search the brand's official pages → Download actual files → Verify hex values against official sources → Write brand-spec.md) with a numeric quality threshold: 5 real brand colors, 10 design tokens, 2 font families, 8pt spacing grid.
  - Design Direction Advisor: 5 schools (Informational=Bloomberg, Editorial=NYT/Medium, Expressive=Stripe/Linear, Functional=Things/OmniFocus, Warm Minimal=Notion/Craft) → 3 recommended directions with visual anchors (3–5 hex colors, type pairing, density, signature detail), then user picks and the system locks.
  - Workflow: define DesignTokens (concrete Swift enum with hex colors, 8pt scale 4/8/16/24/32/48, radii 8/12/16) → layout hierarchy (LazyVGrid, containerRelativeFrame over GeometryReader) → typography hierarchy (display serif 28–34pt, heading 20–24, body 15–17, caption 12–13) → one signature detail → 5-Dimension Review.
  - 5-Dimension Review rubric: Philosophy Consistency, Visual Hierarchy, Detail Execution, Functionality, Originality — each ≥7/10 or the design is not done; radar chart, Keep/Fix/Quick-Wins output.
  - Validation checklist incl. 44×44pt tap targets, dark-mode semantic colors, no GeometryReader/UIScreen.main.bounds.
  - References carry the depth: anti-ai-slop.md (268 lines, per-rule banned/why/instead SwiftUI code), layout-patterns.md (9 layouts, copy-paste code), typography-color.md, design-review.md (151 lines), swift-extensions.md (373 lines, Color(hex:), font and animation extensions called "essential").
  - Honest positioning vs a sibling: a comparison table distinguishes it from swiftui-expert-skill (design vs code correctness; "Use Design first to set direction, Then use Expert", README.md:114-123).
- 3 non-obvious ideas worth adopting:
  1. The Brand Asset Protocol's "verify against official sources" step — forcing hex cross-checks of downloaded brand assets (catches both stale brand kits and hallucinated palettes) with a numeric sufficiency threshold (5 colors/10 tokens/2 fonts/8pt grid).
  2. The 5-school design-direction taxonomy with named exemplar products (Bloomberg/NYT/Stripe/Things/Notion) as a compact shared vocabulary for variant generation.
  3. "One signature detail at 120% effort per screen" — a quantified way to operationalize "spend boldness in one place" (convergent with anthropics' restraint rule, but more prescriptive).
- Flaws / weaknesses:
  - Its replacement recipe is itself a soft default: "single warm accent color", warm neutrals (#FAFAF8), serif display — i.e., the warm-minimal/paper-and-ink look that molveau explicitly lists as the *second-order default* the moment purple gradients are banned. The skill bans one monoculture and recommends another.
  - Numbers are asserted without sources or evals (the ≥7/10 rubric, "3–30 minutes", 5 schools); no evidence the review scores correlate with anything.
  - "Junior Designer Mode" framing is odd (celebrating placeholder-first rather than iteration discipline) and the 6 rules are really 4 anti-slop rules + 2 process rules.
  - Apple-only; no license/attribution chain beyond MIT (README asks to "keep the original author attribution" though MIT does not require it).
- Safety & license: MIT; single skill, prose + markdown templates only — no scripts, no hooks, no telemetry. Nothing executes at install.
