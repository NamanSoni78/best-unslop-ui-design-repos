- What it is: An "awesome list" aggregator for Claude/agent skills that doubles as a Composio marketing funnel: the README's above-the-fold is a dashboard.composio.dev login banner, MCP Gateway promotion, a Quickstart that installs Composio's own connect-apps plugin with an API key, and Discord/X/LinkedIn CTAs. Below that sits a genuinely useful categorized link list.
- Scope: aggregator (link list + vendored folders; not curated in any evaluative sense we could verify).
- Key files read: README.md (structure: head 80 lines, category headings via grep, Document Processing section sample, tail; contents map; entry counts); CONTRIBUTING.md (head 30 lines); repo tree listing (vendored skill folders); .github/workflows presence.
- Mechanics:
  - ~164 linked skills across the main categories (counted `- [` entries within "## Skills" through "App Automation"), plus ~78 more under "App Automation via Composio" (many being Composio's own app integrations). README markets "1000+ production ready" skills (README.md:29); the visible list is ~242 entries — the 1000+ figure appears to count Composio's managed app automations, not reviewed list entries. Categories (11): Document Processing, Development & Code Tools, Data & Analysis, Business & Marketing, Communication & Writing, Creative & Media, Productivity & Organization, Collaboration & Project Management, Security & Systems, Assistive Technology, App Automation via Composio.
  - Entry format: link + one-line description, attribution via "By @author" for community entries; many entries link straight to third-party GitHub repos (e.g. anthropics/skills deep links for docx/pdf/pptx/xlsx, web-artifacts-builder).
  - CONTRIBUTING.md states requirements (real use case, documented, accessible, examples, "Be tested", safe, portable) — but nothing in the README shows evidence of enforcement; it is PR-welcome list curation.
  - The vendored folders duplicate anthropics skills (with their LICENSE.txt files) — i.e., the repo re-hosts skills rather than linking them in several cases, including brand-guidelines and canvas-design verbatim.
- 3 non-obvious ideas worth adopting:
  1. Attribution inline in list entries ("*By @author*") at scale — cheap provenance for a community list (though it is the only quality signal present).
  2. Category taxonomy with a separate "Assistive Technology" section — a slice most aggregators omit.
  3. Nothing else worth adopting; treat it as a cautionary pattern: a list whose commercial sponsor occupies the top third of its README.
- Flaws / weaknesses:
  - Not curated in any verifiable sense: no reviews, no ratings, no install counts, no quality notes, no dates on entries; "1000+" is marketing arithmetic vs ~242 list entries visible.
  - The lead-gen framing is aggressive: login banner, "Join 20,000+ developers", Get Started Free buttons, Discord funnel, and the Quickstart is for Composio's own product. App Automation via Composio (78 entries) is effectively a product catalog embedded in the list.
  - Vendoring anthropics skills without an obvious sync mechanism (no sources.json equivalent) risks silent drift from upstream.
  - Maintenance signals are weak: no last-updated per entry, no CHANGELOG; a .github/workflows dir exists but content not examined; task metadata TBD, so stars/push unknown from files.
  - Some entries are non-skill links (Chrome Relay homepage, tools) mixed with skills — mixed ontology in one list.
- Safety & license: The README teaches installing third-party skills and Composio plugins with API keys ("Paste your API key when asked", README.md:60) — a credentials flow on the front page of a skills list; treat the connect-apps plugin's setup as out-of-scope marketing, not vetted tooling. No hooks/telemetry from the repo itself. Apache 2.0 overall; vendored anthropics folders keep their Apache LICENSE.txt — license chain is okay but per-folder checks are needed for the other 20+ vendored dirs.
- Lineage: links to and re-hosts anthropics/skills content (brand-guidelines, canvas-design, etc., deep-linked and vendored); vercel-labs find-skills cites this repo as a popular source (find-skills/SKILL.md:123). No other lineage stated.
- Install (from README): no single install for the list; per-entry links, and the Composio Quickstart: `claude --plugin-dir ./connect-apps-plugin` then `/connect-apps:setup`.
- Tier suggestion: C (aggregator category) — a link dump with commercial self-promotion and no evaluable curation; useful only as a discovery seed list, not as a quality filter.
