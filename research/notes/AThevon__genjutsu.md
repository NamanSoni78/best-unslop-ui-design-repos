- What it is: A Claude Code skill pack: three user-facing skills — cast (animate one interface), paint (design a product's look, generates MASTER.md design system), bunshin (whole website via subagent "clones" with an art-director loop) — plus 18 internal `_jutsu/*` modules (motion principles, stack modules for Web/Compose/SwiftUI, tells, design-audit, vendored ui-ux-pro-max). Everything hangs off a "validated thesis" gate.
- Scope: UI (Web + Android Compose + Apple SwiftUI; bunshin web-only)
- Key files read: README.md, LICENSE, CREDITS.md, skills/cast/SKILL.md, skills/_jutsu/tells/SKILL.md, skills/_jutsu/design-audit/SKILL.md, skills/paint/SKILL.md (grep), skills/bunshin/SKILL.md (grep), scripts/check-no-verbatim.sh, evals/README.md, skills/_jutsu/ listing
- Mechanics:
  - Thesis-gated pipeline: no code without a validated interaction thesis (cast) / visual+interaction thesis (paint); the thesis's `Allowed patterns:` line is the ONLY authority for what patterns are permitted; requests must be written into the thesis before building, else they read as tells at audit time.
  - Tells module: "a tell is a default the thesis never asked for" — four families (invented information, decorative filler, reflex convergence, hollow copy); each entry has exactly three fields (marker, why-it's-a-tell, a question back to the thesis — never a replacement, "a replacement would only be the next default").
  - design-audit: `python3 audit.py` runs check groups incl. 18 tells checks; findings vs clean vs **not-applicable are reported as "not checked", never as passing** — after a real bug where greps anchored on `src/` matched nothing in app-router projects and empty output was read as clean. Per-check tests assert each check can still fire.
  - Preview gate: user chooses once how to see theses (rendered page / live preview / inline); "approving an easing curve you cannot see is not approval, it's a guess"; preview is throwaway and never becomes the implementation.
  - bunshin: multi-agent orchestration — art director + per-page builder subagents + reviewers + fix rounds; ends on a rule (minor-only verdict, round cap of tier, or a round that fixes nothing); announces token cost and asks twice; steps down to paint/cast when the host can't spawn subagents.
  - Honest-voice rule: ninja-flair during execution, plain factual language in reports/audits — the flair is specified to disappear the moment a result lands.
  - Evals: `claude plugin eval` with-without ablation across 7 cases (studio-landing, saas-landing, thesis-allows [over-correction control], swiftui-skip, bunshin-escalates/steps-down routing tests); "the number that matters is the delta, never the runner's exit code".
  - Vendored engine: skills/_jutsu/ui-ux-pro-max vendors nextlevelbuilder/ui-ux-pro-max-skill's dataset + Python search engine (MIT, LICENSE-upstream.txt, UPSTREAM.md).
- 3 non-obvious ideas worth adopting:
  1. Tells-without-replacements: catalogue only names the tell and asks a question back to the thesis — refusing to ship a replacement because "a replacement would only be the next default"; genjutsu explicitly "does not ship a look".
  2. check-no-verbatim.sh: a CI-style guard that no 10-consecutive-word run is shared with the repos it learned from (pinned commit, code spans excluded) — makes "inspired-by, not copied" a checked claim instead of a hope.
  3. `not applicable ≠ passing` in audit output (and the war story that motivated it: empty grep output read as a clean bill of health right before delivery) — an evidence-honesty distinction most linters still get wrong.
- Flaws / weaknesses:
  - Heavy persona/terminology (jutsu, genjutsu, bunshin, "sealing the easing pattern") raises the learning curve; mitigated by the plain-report voice rule but still pervasive in docs.
  - Multi-platform claims exceed evidence: README admits "Developed and run on Claude Code only, with one SwiftUI case and no Android run recorded"; Compose/SwiftUI tells are explicitly "not covered yet".
  - bunshin's 10.5M-subagent-token cost example is real but steep; capability depends on host subagent/workflow tooling (documented fallbacks, but the marquee register is the least portable).
  - The npx install URL (genjutsu.athevon.dev) is a custom endpoint — installs from a site rather than the repo ("`npx skills add AThevon/genjutsu` installs the skills without their modules").
