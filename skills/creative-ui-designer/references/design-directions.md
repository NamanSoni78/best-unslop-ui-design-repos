# Design directions — axes and archetypes

Use this to *generate* directions, not to pick one. Vary at least three axes
between candidates; choosing one archetype three times is one direction.

## Generation axes

- **Type personality:** humanist sans / geometric sans / transitional serif /
  slab / mono-as-identity / mixed serif display + sans body. Ask: which voice
  would the product's author recognize as theirs?
- **Color logic:** one hue + neutrals / duotone / editorial B&W + a single
  accent / warm neutrals (paper, bone) / high-chroma on demand. The logic is the
  choice — which colors may touch which, and what the accent is *allowed* to do.
- **Structure:** single-column editorial / asymmetric split / dense tool grid /
  full-bleed media / document-like. Pick from the job (scan vs read vs operate).
- **Density:** sparse-calm (a lot of nothing) / editorial (rhythm and air) /
  dense-utility (operators want density). Density is a promise to a user type.
- **Motion:** almost none / feedback-only / choreographed reveals. Default to
  feedback-only (120–180 ms ease-out; 200–350 ms for reveals; nothing bounces
  unless the brand demands it; interactions used 100+/day get zero animation).

## Archetypes (starting points, not destinations)

- **Editorial:** a strong serif voice, generous measure, rules and overlines,
  hierarchy from scale not boxes. Suits content with authority; risks the
  post-ban "thin serif + italic" default if chosen reflexively.
- **Utilitarian dense tool:** monospace numerics, tight rows, keyboard-first,
  chrome over decoration. Suits operators; risks coldness.
- **Warm tactile:** warm neutrals, soft geometry, humanist type, photography of
  real things. Suits food, craft, local, hospitality; risks cream+terracotta
  default — pick warm *because the subject is*.
- **High-contrast minimal:** near-monochrome, huge scale jumps, one accent used
  as a verb (only on actions). Suits portfolios, manifests, launches.
- **Documentary/full-bleed:** one dominant photograph or artifact, type as
  caption, structure borrowed from the artifact itself.

## Domain borrowing

The richest direction source: what does this domain's *physical* world look
like? Tickets, menus, wayfinding, spreadsheets, control panels, timetables,
field guides, receipts, maps. Borrow structure and texture from there — not
cards-in-a-grid from another SaaS.

## Pairing sanity checks

- Two typefaces, one job each (display voice vs body legibility); a stated
  scale ratio (1.2 / 1.25 / 1.333), not eyeballed sizes.
- Accent color appears on <10% of pixels and points at actions or the single
  most important datum.
- Radius and borders: one system, one reason (grouping), zero decorative boxes.
- When two directions feel close, the difference is decoration — go back and
  vary structure or density instead.
